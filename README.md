# FindWare

### Sistema Inteligente de Localização de Produtos

O FindWare é um sistema desenvolvido para auxiliar na localização e no gerenciamento de produtos em um Centro de Distribuição.

O projeto foi desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas do SENAI, unindo conhecimentos de tecnologia e logística para solucionar um problema real de organização e localização de produtos.

## 🎯 Objetivo

Facilitar a localização, movimentação e controle de produtos dentro de um Centro de Distribuição, tornando os processos mais organizados, rápidos e eficientes.

## ⚙️ Principais funcionalidades

- Cadastro de produtos
- Consulta de produtos
- Localização por corredor e prateleira
- Controle de entrada e saída
- Registro de movimentações
- Histórico de movimentações
- Mapa do Centro de Distribuição
- Busca de produtos
- Identificação de produtos
- Controle de usuários e níveis de acesso

## 💻 Tecnologias utilizadas
